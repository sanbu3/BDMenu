# BDMenu 扩展应用栏 · Dock companion

从 2.3 起，Dock 页面管理的是 **BDMenu 自己提供的扩展应用栏**。它能直接固定到某块屏幕，或跟随鼠标所在屏幕，不负责搬移或复制原生系统 Dock 的全部能力。

## 为什么更换方案

外置大屏在上、MacBook 内建屏在下方中央时，上屏底边中央是跨屏通道。鼠标持续下移会进入下屏，不能据此保证在上屏呼出原生 Dock。2.2 的底边保护只能拦截部分召唤动作，不能将已经在下屏的系统 Dock 搬回上屏，已在 2.3 移除。相关实机研究可参考 [DockKeeper 的上下布局记录](https://github.com/blamechris/DockKeeper/blob/main/docs/spikes/separate-spaces-pinning.md)。

## 使用

1. 控制中心顶部 **Dock** 页（⌘5），开启“启用扩展应用栏”。快捷面板和菜单栏右键也有 Dock 设置入口。
2. 选择 **固定到指定屏幕**，再点选目标。应用栏立即显示在该屏幕内部下方，包括底边连接着其他屏幕的上方显示器。
3. 或选择 **跟随鼠标所在屏幕**。鼠标进入新屏幕后短暂停留，应用栏跟过去，不需要推底边。拖动或操作应用栏时暂停迁移。
4. 点击图标打开或切换应用；默认再点前台应用会隐藏它，再点隐藏应用则恢复。可在 Dock 页关闭点击隐藏。运行中的应用有圆点，当前应用使用蓝色圆点。应用较多可横向滚动。
5. 右端设置按钮打开本页；右键可快速选择跟随模式、固定目标或关闭应用栏。应用图标右键提供打开、显示应用窗口、隐藏／显示、保留在扩展栏、在访达中显示、系统原生菜单入口及正常退出；访达不提供退出。

## 内容与隐藏

默认显示系统 Dock 固定的应用和正在运行的普通应用，保留固定应用顺序并去重。可关闭固定应用同步，仅显示运行中的应用。读取原生固定项，不写入或修改它们。右键“保留在扩展栏”用于本地固定／移除，额外固定项和对同步项的排除只保存到 BDMenu；运行应用取消固定后仍显示到它退出。

默认保持可见。开启“自动隐藏扩展应用栏”后，把鼠标移到它所在屏幕内部的底部区域即可显示，离开后收起。触发区域在屏幕内，不需要越过上下屏幕接缝。不改变系统 Dock 自动隐藏偏好。

## 单屏、断连和镜像

- 只有一块在线屏幕时自动在那里显示，保留固定目标；回到多屏后继续按偏好运行。
- 多屏固定模式下，如果目标停用或断连，应用栏暂停，不自动误绑其他目标；重新启用原目标后恢复，也可以手动选新目标。
- 镜像屏幕共用同一桌面，不提供两份独立内容。正常退出关闭扩展应用栏及其监听。

## 范围

支持应用启动／切换／隐藏／恢复、运行状态、固定／跟随、自动隐藏及横向滚动。暂不包含系统 Dock 的废纸篓、文件夹堆栈、窗口预览和完整拖放管理；不会隐藏、重启或改写原生 Dock。

应用栏使用非激活式透明 NSPanel，定位在目标屏幕内部，避免与下方屏幕重叠。不拦截鼠标跨屏，不移动指针，不改分辨率、主屏、屏幕排列或 Spaces 设置。基础应用栏不新增辅助功能权限要求；“系统 Dock 原生菜单…”需要辅助功能权限，仅通过系统 Dock 对应图标打开它自己的菜单，位置由系统决定，不会把菜单搬到扩展栏旁。亮度快捷键、验证入口辅助仍按各自功能申请权限。


### 右键菜单的边界

“打开”始终执行打开／切换，不触发点击隐藏。“显示应用窗口”会恢复隐藏并激活窗口，不是系统 Dock 的 App Exposé。退出发送正常退出请求，应用可能要求用户保存或确认，不强制结束进程。

“系统 Dock 原生菜单…”只在应用已运行或有系统固定图标时可用；需要辅助功能权限。它调用真实系统菜单，不枚举或复制最近文档等菜单内容。原生菜单不会被重新定位到扩展栏，支持情况与窗口位置由 macOS 决定，失败时在设置页给出结果。
