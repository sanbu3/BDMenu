# 多显示器 Dock 管理

“跟随鼠标”沿用 macOS 手势：将鼠标移到目标屏幕底边并继续向下移动，即可呼出 Dock。选择这一方式不会移动指针。

“固定屏幕”按显示器 UUID 保存目标，仅在至少两块扩展显示器同时启用时运行。它会防止其他屏幕普通底边的鼠标移动触发 Dock 迁移；请先在指定屏幕的露出底边呼出 Dock。定位引导帮助找到目标屏幕，当前位置来自 Dock 窗口几何信息。

固定保护适用于底部 Dock，需要已有辅助功能权限。拖动、边角和相邻屏幕间的通道保留，系统仍可能从这些路径、唤醒或系统操作重新分配 Dock。这种情况可在指定屏幕底边再次呼出。完全遮挡的底边不能作为呼出入口，界面会暂停并说明；断开目标或进入镜像模式也会暂停，不改主屏、不更改显示器排列。

系统行为参考 [Apple 桌面与程序坞设置](https://support.apple.com/en-euro/guide/mac-help/mchlp1119/27/mac/27)；底边事件保护思路参考 [DockPin](https://github.com/chansigit/dockpin)。
