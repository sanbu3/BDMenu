# Dock 设置：单屏与多屏

入口：控制中心顶部 **Dock** 页（⌘5），或菜单栏右键 → **Dock 设置…**，或快捷面板 → **Dock 设置**。

“跟随鼠标 · 底边呼出”沿用 macOS 手势：将鼠标移到目标屏幕底边并继续向下移动，即可呼出 Dock。选择这一方式不会移动指针。仅把鼠标移到另一块屏幕，不会立即迁移 Dock。多屏底边呼出需要底部 Dock 和“显示器具有单独的空间”；不符合时，运行状态会解释原因并提供系统设置入口。

“固定屏幕”按显示器 UUID 保存目标，仅在至少两块扩展显示器同时启用时运行。它会防止其他屏幕普通底边的鼠标移动触发 Dock 迁移；请先在指定屏幕的露出底边呼出 Dock。定位引导帮助找到目标屏幕，当前位置来自 Dock 窗口几何信息。

固定保护适用于底部 Dock，需要已有辅助功能权限。拖动、边角和相邻屏幕间的通道保留，系统仍可能从这些路径、唤醒或系统操作重新分配 Dock。这种情况可在指定屏幕底边再次呼出。完全遮挡的底边不能作为呼出入口，界面会暂停并说明；断开目标或进入镜像模式也会暂停，不改主屏、不更改显示器排列。

系统行为参考 [Apple 桌面与程序坞设置](https://support.apple.com/en-euro/guide/mac-help/mchlp1119/27/mac/27)；底边事件保护思路参考 [DockPin](https://github.com/chansigit/dockpin)。


单屏时：Dock 只能出现在唯一启用的屏幕。模式仍可切换，固定目标仍可选择与保存，底边保护保持关闭；增加第二块屏幕后自动按偏好运行。已停用或断开的屏幕不能显示 Dock，不会为了选择 Dock 目标自动启用屏幕。

“指定屏幕”列表始终可见。点选只保存目标；跟随模式下仍自由呼出，固定模式下保护指定目标。点击“所选屏幕呼出引导”展示位置说明，再由用户移到目标底边完成原生呼出；不是一键搬移，也不会移动鼠标或改变主屏。macOS 未提供本应用可用的公开跨屏搬移接口；为保持用户选择的指针不跳动，不使用鼠标瞬移来模拟迁移。
