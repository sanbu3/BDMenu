# BDMenu 2.0 界面与交互

BDMenu 使用蓝色强调、系统材质、较大的系统字体和胶囊控件。常用动作在菜单栏完成，完整配置放到可调整大小的原生控制中心。

| 界面 | 用途 | 状态来源 | 入口与退出 |
| --- | --- | --- | --- |
| 快捷面板 | 亮度、屏幕启停、全部点亮 | 每屏 Controls 和连接状态 | 左击菜单栏图标；Esc 或点外部关闭 |
| 显示器 | 音量、分辨率、输入源、主屏、镜像与恢复 | DisplayManager | 控制中心，⌘1 |
| 快捷键 | 目标屏幕、录制、精细步进、权限恢复 | BrightnessKeys 与已保存绑定 | 控制中心，⌘2；Esc 取消录制 |
| 自动化 | 外接屏工作流、键盘背光、密码入口辅助 | 各功能的实际状态 | 控制中心，⌘3 |
| 应用与权限 | 应用外观、登录启动、权限、版本 | NSApp 外观、SMAppService、AX 记录与监听状态 | 控制中心，⌘4 |
| 亮度 HUD | 在目标屏幕提示亮度 | 亮度操作值 | 非激活透明面板，自动消失 |

## 交互原则

- 在线主屏排在前面，停用屏幕排在后面，优先暴露正在使用的屏幕。
- 快捷面板的底部操作保持可见；屏幕多时只滚动列表。Hosting controller 随 SwiftUI 的首选内容尺寸更新。
- 关闭控制中心不会退出应用；重新打开应用可找回控制中心。菜单栏右击可打开控制中心、快捷键或退出。
- 所有选项自动保存；使用纯外观选项不会改动系统全局外观。
- 保留最后一块屏幕的保护，硬件能力未知时不允许调节，正在应用时禁用冲突操作。
- 快捷键录制时有明确状态和取消入口；切页、关闭窗口或离开应用取消录制。
- 自定义按钮保持原生按钮的键盘行为，在胶囊边缘绘制匹配形状的焦点。原生开关保留原生辅助功能与键盘语义。
- 权限文字区分“系统已允许”与“亮度按键正在监听”；滑块不依赖按键监听授权。
- 密码优先只尝试选择系统设置、软件安装等系统授权窗口中的“使用密码”。不宣称覆盖锁屏或所有第三方应用，不读取、代填或提交密码。

## 窗口与材质

- 控制中心是原生带标题栏、可调整大小的窗口，最小内容尺寸 720×560；标题栏不透明，不透出后方窗口。
- 快捷面板使用系统 NSPopover，保持系统的边缘裁切与关闭行为。
- 两个 hosting controller 的根图层明确清空，SwiftUI 仅在内容区域绘制材质。
- HUD 明确关闭 AppKit 阴影，清空 hosting 图层，胶囊内绘制材质与描边，不额外叠加外部黑色阴影。
- 只有系统弹出面板的原生过渡；开启“减少动态效果”时关闭 popover 动画。


## 2.1 定制窗体

用户明确要求控制中心去掉原生标题栏，因此这里采用透明、无阴影、可成为主窗口的 borderless NSWindow。SwiftUI 根表面负责 26 点圆角与一像素轮廓，hosting 图层显式透明。窗体底层使用 behind-window 系统材质以保证深浅色对比度；其余卡片保留 SwiftUI 系统材质。头部关闭与最小化按钮使用圆形焦点轮廓；品牌区域提供原生拖动，右下角提供缩放，保持左上角不变并限制最小尺寸。全局菜单继续提供键盘命令。

亮度 HUD 为 280×88 的非激活面板，数字与文字共用基线，整体内容居中。横坐标由目标屏幕 frame 中点计算，不跟随侧边程序坞偏移；纵坐标在 visibleFrame 底边上方 32 点，不抢走当前窗口焦点。

验证偏好每 700 毫秒在后台确认实际状态。内建屏在线且系统报告 Touch ID 可用时选择指纹偏好，其余在线屏幕场景使用密码偏好；改变屏幕状态会改变偏好。仅在明确的 Apple 系统授权方法按钮存在时操作，不取消或重开授权、不改变系统认证策略、不访问密码内容。同一窗口同一偏好只选择一次，用户后续选择不被反复覆盖。
